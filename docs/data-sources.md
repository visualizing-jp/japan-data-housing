# データソース

「日本人はどんな家に住んできたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-04。軸は e-Stat API のメタ取得・実測値で確認済み。

## 1. 結論

住宅ストック（持ち家・借家、建て方、広さ、空き家）を、**時代・形態・地域**の3ビューで見せる。
単位は**住宅数**とその構成比・率（一般世帯数と混同しない）。

一次ソースの骨格は、社会・人口統計体系（都道府県データ）の「Ｈ　居住」。
これは住宅・土地統計調査などの公表値を横断接続した指標群で、全国＋47都道府県×調査年が揃う。
空き家の種類内訳は、住宅・土地統計調査の「居住世帯の有無」表を年次ごとに正規化して載せる。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 社会・人口統計体系 基礎データ Ｈ居住 | `0000010108` | 指標×全国×年 | 住宅数・構成比 |
| 時代（率） | 同 社会生活統計指標 Ｈ居住 | `0000010208` | 指標×全国×年 | 持ち家比率・空き家比率など |
| 形態 | 上記＋居住室畳数階級 | 同上 | 次元×カテゴリ×年 | 住宅数・構成比 |
| 形態（空き家種類） | 住宅・土地統計調査 | `0003095315` / `0003326560` / `0004015740` | 種類×全国×年 | 住宅数・構成比 |
| 地域 | `0000010108` / `0000010208` | 指標×都道府県×年 | 率・相対指標（全国比） |

出典表記: 総務省「住宅・土地統計調査」（社会・人口統計体系経由含む、e-Stat）。

## 2. 採用データセット（メタ・実測）

### `0000010108` — 都道府県データ 基礎データ「Ｈ　居住」

- 軸: 観測値(1) × Ｈ居住(507) × 地域(48: 全国+47県) × 調査年(51: 1975–)
- 住宅・土地統計由来の件数は **1978, 1983, 1988, 1993, 1998, 2003, 2008, 2013, 2018, 2023** の10時点（全国実測）
- 調査年コードは `YYYY100000`（「YYYY年度」）
- 採用コード例:
  - `H1100` 総住宅数 / `H1101` 居住世帯あり / `H110202` 空き家数
  - `H1310` 持ち家 / `H1320` 借家 / `H1321` 公営・UR・公社 / `H1322` 民営借家 / `H1323` 給与住宅
  - `H1401` 一戸建 / `H1402` 長屋建 / `H1403` 共同住宅 / `H1404` その他
  - `H2130` 1住宅当たり延べ面積
  - `H2101`–`H2108` 居住室の畳数階級

### `0000010208` — 社会生活統計指標「Ｈ　居住」

- 率・平均値。同上の調査年で接続可能（実測）
- 採用コード例:
  - `#H01301` 持ち家比率 / `#H01302` 借家比率 / `#H0130202` 民営借家比率
  - `#H01401` 一戸建住宅比率 / `#H01402` 長屋建 / `#H01403` 共同住宅比率
  - `#H01405` 空き家比率

### 空き家種類（住宅・土地統計調査）

| 年 | statsDataId | 表題 |
| --- | --- | --- |
| 2013 | `0003095315` | 居住世帯の有無(9区分)別住宅数―全国，３大都市圏，都道府県，21大都市 |
| 2018 | `0003326560` | 住宅総数 居住世帯の有無(9区分)別住宅数－全国，都道府県 |
| 2023 | `0004015740` | 住宅総数 居住世帯の有無(9区分)別住宅数－全国、都道府県 |

**2023年は空き家下位分類のコード意味が入れ替わっている**（メタ実測）。

| 意味 | 2013 | 2018 | 2023 |
| --- | --- | --- | --- |
| 二次的住宅 | `00009` | `221` | `224` |
| 賃貸用 | `00012` | `222` | `222` |
| 売却用 | `00013` | `223` | `223` |
| その他の空き家 | `00014` | `224` | `221`（「賃貸・売却用及び二次的住宅を除く空き家」） |

配信では意味ラベルに正規化し、年次横断のコード直結はしない。

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 国勢調査の住宅の建て方・所有関係 | households との調査年接続には有用だが、空き家が無く分母も「居住世帯のある住宅」。SSDS で住宅・土地統計系が揃うため第1版は注記のみ |
| 市区町村・メッシュ | スコープ外 |
| 家賃・価格 | スコープ外 |
| 空き家将来推計 | 公式の長期接続が弱い |

## 4. 接続・分母ルール

- **空き家率** = 空き家数 / 総住宅数（`#H01405` と整合）
- **持ち家比率・建て方比率** = 居住世帯あり住宅を分母とする公表率（`#H01301` 等）。件数は `H1310` 等
- 時代ビューで件数と率を縦積みし、分母の違いを注記で明示
- 地域の相対指標: `県の率 / 全国の率`（率系）。延べ面積も同様
- 空き家種類の構成比は空き家総数を分母（総住宅ではない）

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | dwellings, rate, share | metrics |
| `form.json` | dim × code × year | dwellings, share | dims, codes |
| `geo.json` | metric × year × area | value, relative | metrics, areas |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 単位は住宅。世帯ダッシュボード（一般世帯）と分母が異なる
- 住宅・土地統計は概ね5年ごと。社会・人口統計体系経由の接続値
- 2023年の空き家種類コードは2018以前と意味が入れ替わっている（表示は正規化済み）
- 持ち家比率の分母は居住世帯あり住宅。空き家率の分母は総住宅数
